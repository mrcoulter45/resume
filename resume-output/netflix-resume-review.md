## Remaining evidence with the highest return

1. Representative agent tasks with model/client/revision/date, repeated outcomes, failures/interventions and before/after quality. Current outcome checks are useful; measured agent improvement would answer a different part of Netflix's evaluation requirement.
2. Exact active users/teams, frequency, rollout/support expectations and real operating incidents. Shared professional use is established; scale and reliability responsibilities need specifics.
3. One or two backend API designs personally delivered: contract, consumers, compatibility/versioning tradeoffs and developer feedback.
4. Memory storage/retrieval/freshness behavior, failure recovery and observed usefulness across tasks; permission enforcement mechanisms in specific skills rather than only policy text.
5. Measured engineering/business value, including repair effort or attributable stakeholder outcomes. The hours-to-days manual baseline remains an observation, not a controlled time-saving percentage.

These are evidence opportunities, not reasons to relabel delivered work as prototypes. The revised document makes a stronger, concrete senior-engineering case without claiming that every Netflix specialty is established or assigning an interview probability.
